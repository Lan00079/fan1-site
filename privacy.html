隐私政策

fan1.top · fan1 汉化工具 · 更新于 2026-09

工具本地运行

fan1 汉化工具完全在您的电脑上本地运行，不收集、不上传任何个人信息。

  • 您的翻译接口配置（API 地址/密钥）仅保存在本机 exe 同目录的 games 文件夹，不经过我们的服务器。
  • 游戏数据、缓存与译文全部保存在本地，删除 games 文件夹即彻底清除。

本网站（fan1.top）

  • 本站为静态页面（GitHub Pages），不设用户账号、不设登录、不收集表单信息。
  • 本站接入第三方广告服务（HilltopAds），它们可能通过 Cookie 采集访问数据用于广告投放，详见服务商隐私政策。您可通过浏览器设置管理或清除 Cookie。

工具的网络行为

  • 下载游戏资源时连接 freem.ne.jp 及其 CDN（fgamearchives.com / fplay.xyz）。
  • 启动时的版本检查仅访问 GitHub Releases 读取最新版本号，不含任何个人标识。
  • 工具内广告（如启用）由第三方广告服务商按其政策处理。

联系方式

对本政策有疑问可通过 GitHub 仓库 issue 联系。
