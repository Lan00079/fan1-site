# tsd-mod — teach sister to drive 一键 Mod(人格 / 音色 / 模型接口 / 云端 TTS)

对本机已购买的游戏副本做本地化修改:**角色人格替换(全量中文提示词)+ 中文音色克隆源替换 + 模型接口替换(可选,自备 API key)+ 云端 TTS(可选,弱硬件机器也能流畅克隆音色)**。全部修改可一键还原,不触碰任何在线玩家数据。

> ⚠️ 免责声明:仅供学习研究语音克隆与提示词工程技术的本地实验工具,与游戏开发商无关。
> 请勿分发修改后的游戏文件或主播声音素材;模型接口功能请仅使用自己注册的 API key。
> 使用本工具产生的一切后果由使用者自行承担。

## 使用(图形面板,推荐)

1. **双击 `tsd-mod.exe`** — 打开控制台面板(无需安装 Python):
   - 顶部自动显示三层 mod 状态;
   - 「人格 / 音色」单选切换(含"原版");
   - key 输入框(留空 = 该平台走游戏官方免费额度);
   - 点「应用」= 按面板选择一键应用(自动先备份/还原,重复点击幂等);
   - 「还原游戏原版」= 一键回原版;
   - 「启动服务 + 游戏」= 起本地服务并拉起 Steam 游戏。
2. 应用后从 Steam 启动游戏(或用面板的启动按钮)。设置改动需重启游戏生效。

## 命令行方式(可选)

```
python mod.py doctor / install / status / restore / start / server
```
功能与面板等价,`--persona` `--voice` `--no-iface` 参数见 `python mod.py -h`。

## 玩法开关

| 想要 | 命令 |
|---|---|
| 换人格(东雪莲/孙笑川) | `python mod.py restore` → `python mod.py install --persona <名>` |
| 换音色 | `python mod.py restore` → `python mod.py install --voice <名>` |
| 只改人格/音色,不动 DLL | `python mod.py install --no-iface` |
| 彻底还原游戏原版 | `python mod.py restore` |
| 查看当前状态 | `python mod.py status` |

- 内置人格:`dongxuelian` / `sunxiaochuan`(persona_full_*.txt 可自行仿写新增)
- 内置音色:`voice_ref/<名>/ref.wav + ref.txt`(替换成自己的素材:5~13 秒干声 + 逐字文字稿)
- 写新人设:仿 `persona_full_<名>.txt`,保留锚点标题行和"其余格式规则按下文执行"

## 原理(四层)

1. **接口层** `iface_patch.py`:重写 `Assembly-CSharp.dll` 字符串堆里的 5 个凭证云函数 URL 指向本地服务 + 遥测静音 + 阿里线重定向;本地服务(`fake_creds_server.py`)返回你自己的 key(协议:`{"token":..,"expiresAt":..}`),大流量直连官方端点不经过本机。
2. **人格层** `prompt_patch.py`:重写 `resources.assets` 里全部 42 份 zh-CN 系统提示词的人格段——场景段(#Goal)与输出协议段(#Output format 的结构化车控)原样保留;原地缩短写入,偏移零变化。
3. **音色层** `voice_patch.py`:游戏 TTS(OmniVoice)是 zero-shot 声音克隆,把中文克隆源("zh" AudioClip)替换为 RIFF WAV 封装的你的参考音频,并同步 OmniVoiceConfig 的参考文字稿。
4. **TTS 桥层** `bridge_patch.py` + `sf_tts.py`:DLL 里 Python TTS 进程启动名 `generator`→`ttsbridge`(等长),游戏拉起的是本工具的 9KB 代理桥;桥按 `.runtime/ttsbridge.json` 转发——云模式转到本地服务 :9870(`sf_tts.py` 把游戏的两种 TTS 方言 `/_hck`、`/tts` 翻译成硅基流动 `/v1/audio/speech`,自定义音色=云端上传的参考音频),GPU 模式转到预热的 generator.exe。

## 还原

`python mod.py restore` — 从 `pristine/` 恢复全部四个文件为首次安装时的原版。

## 语音后端说明(重要——按机器配置选)

面板「TTS 引擎」二选一:

### 云端 API·硅基流动(发布版默认推荐,零 GPU)

显存不够/没有独显/笔记本弱机的机器选这个——**克隆音色的推理全部在云端完成,本地零 GPU 占用**:

1. 注册[硅基流动](https://siliconflow.cn),在面板「硅基流动 SiliconFlow」一栏填入你的 API key;
2. 选中想用的音色,点「**设为云端音色**」——克隆走 references 内联: 参考音频+逐字文字稿随每次合成请求直接携带,**无需上传注册**,可点「试听云端音色」确认效果;
3. TTS 引擎选「云端API」,点「应用」,之后每次玩都从面板「**启动服务 + 游戏」**进(本地服务 :9870 负责把游戏的 TTS 请求转发到硅基流动);
4. 想换音色:选中新音色 → 再点一次「设为云端音色」即可,无需重启游戏(服务每次请求重读配置)。

- 模型 `FunAudioLLM/CosyVoice2-0.5B`,计费 **¥0.05/千字符**——按台词量玩一晚上通常几分钱到一两毛钱;
- 参考音频不落任何第三方库,每次请求从本机直传合成;实测一句话 1~2 秒返回(比本地原生引擎更快);
- 无 key 或服务没启动时,游戏会自动回退到原版引擎(音色退回内置)。

### 本地 GPU(原版 generator.exe,无需账号)

有合格显卡的机器可以不依赖任何云服务,游戏自己的两套克隆引擎照常工作:

- **native DLL**(.gguf): 读游戏资产里的中文克隆源(voice_patch 替换)——RTF≈1~2,合成时占 GPU
- **Python 后端**(generator.exe,GPT-SoVITS api_v2 协议): 读 `Plugins/.runtime/` 参考音频
  (sovits_patch 替换)——实测 RTF≈0.35,**快 3~6 倍**,中档画质下游戏会自动切换到它

默认画质=**中档**(推荐,面板可切换):开场几句走原生引擎(短句约 2~3 秒/句),
随后自动切换到快速 Python 后端(实测 RTF≈0.35,约 1.8 秒合成 5 秒语音),两套引擎都用你导入的音色。
选**低档**则用 LightTTS(内置固定音色,MeloTTS 无克隆能力——音色 mod 不生效,但零 GPU 负担最流畅)。

两种模式下「TTS 代理桥」(ttsbridge.exe)都生效:游戏启动会话时拉起的是本工具的代理桥,
立即绑定端口过健康检查(消除原生垫场的 8~19 秒开场慢),再转发到对应上游
(云模式=本地服务:9870→硅基流动;GPU 模式=预热好的 generator.exe)。

音色包来源标记: 每个音色目录含 `credits.json`(来源/作者/许可证),面板导入时会询问并记录,
应用时在日志展示。内置音色来自 fish.audio 公开样例,仅限本地学习研究。

## 已知边界

- 云端模式需要联网到 api.siliconflow.cn;key 额度耗尽/欠费时游戏自动回退原版引擎。
- GTX 1060~1080 级显卡**本地**合成一句话约 5~20 秒(RTF≈1),台词越短越快;显存不足时游戏会自动降级 TTS 引擎(音色退回内置)。——弱机器请直接用云端模式,无此顾虑。
- Steam 校验文件完整性会还原 DLL,重跑 `python mod.py install` 即可。
- 语音识别(STT)仍走游戏原版云端通道;OpenAI Realtime 线不经过本地服务(需 WS 级劫持,未实现)。
